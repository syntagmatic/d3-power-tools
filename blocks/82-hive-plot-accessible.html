Accessible Hive Plot

80 nodes on 3 structural axes (source / connector / sink) with ~120 edges. Keyboard navigable with screen reader support.

Hover or navigate to a node to see details.
Keyboard navigation
Tab to enter the plot
← → switch between axes
↑ ↓ move along axis (sorted by activity)
Home / End jump to first / last node
Enter or Space select node and highlight connections
Escape clear selection
