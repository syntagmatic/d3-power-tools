---
name: commit message style
description: User wants moderately detailed commit messages — not one-liners, not walls of text
type: feedback
---

Commit messages should have a concise subject line plus a short body describing the key changes. Not ultra-brief one-liners, but not multi-paragraph essays either. 2-4 lines of body is the sweet spot.

**Why:** User found single-line commits too terse and multi-paragraph ones too verbose.

**How to apply:** Write a clear subject line, then a body with the main changes. Skip obvious details but include enough that someone reading `git log` understands the scope.
