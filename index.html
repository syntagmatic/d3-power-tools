D3 Power Tools

Skills for building advanced D3.js visualizations.

Use

Each skill encodes the judgment calls behind a visualization type — where the tick falls, when to use color vs. position, why this projection. They load automatically in AI coding tools when your prompt matches.

Install instructions for Claude Code, Gemini CLI, and Antigravity. Skills are plain markdown — humans can read them directly. What are datavis skills? · What are design skills?
