# Exploratory Visualization Design

The viewer is a detective, not a reader. Open a thinking space — don't
guide to an answer.

## Before code, answer these

1. **See the data.** Profile shape and structure before choosing a form.
   Dimensions, distributions, clusters, gaps. Hierarchical, relational,
   temporal, spatial, high-dimensional?

2. **Define the task.** What does the viewer DO — not see. Discover,
   compare, relate. Exploration before explanation.

3. **Find the natural form.** Match the form to the data's structure —
   don't flatten what's naturally complex. Interaction is integral to
   the form, not added after: every interaction answers a question the
   viewer might ask. Coordinate views when one can't hold the full
   structure — understanding emerges from how views respond together.

Complexity matches the data. Sub-100ms response = thinking with the
tool. Animation only for object constancy.
